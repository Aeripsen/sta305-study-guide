# STA305 study pack

My revision notes for **STA305H1 S, Design and Analysis of Experiments**, University of Toronto,
Summer 2026, taught by Dr. Luai Al Labadi. Final exam: Tue 18 Aug 2026, 9:00 to 12:00, EX 200.

## Files

- **`STA305.pdf`** (33 pages) - the one to read, print and highlight. White, everything expanded,
  nothing scrolls sideways, real text layer so search and annotation work.
- `STA305.html` - the same content as an interactive page, with solutions collapsed so you can
  attempt each question before revealing it. Needs the `katex/` folder beside it.
- `katex/` - KaTeX vendored locally, so the page renders offline with zero network requests.

## How it is built

Questions are the spine. 52 of them, each followed by:

1. **What this question is really asking** - what he is actually testing, where the trap is,
   and what shape the answer takes, before any algebra.
2. **The full solution**, one step per line, with a **why** note under each line explaining where
   that number came from.

Structure: reference card, Part 0 (what every symbol means and why ANOVA exists), then four complete
past papers, extra drills for the units those papers missed, 17 question variants, 20 multiple choice,
and a predicted 8-question paper.

## Sources

Questions are quoted from the posted W2025 Term Tests 1 and 2, the W2023 final and its answer key,
the Summer 2026 Test 1 and Test 2 solutions, and Practice Problems 1 to 9. All arithmetic was
re-derived and checked against the posted answer keys.

**This repository is private.** Those questions are the instructor's intellectual property and the
syllabus restricts course materials to students currently enrolled. The `.gitignore` also excludes
every original course file (`course/`, `raw/`).
